Lightning TDOA Simulator

Simulation of a 3-station VLF lightning detection network using TDOA multilateration, and study of achievable accuracy under controlled noise.

Context

Originally a hardware project: a 3-node VLF lightning detector with loop antennas, ESP32 acquisition boards and GPS modules for time synchronisation. The prototype reached a functional state but was never finalised, and the original code was not preserved.

This simulator reconstructs and formalises the algorithmic part that survived, to answer questions the prototype never had time to settle empirically. The principle in one sentence: three stations timestamp the pulse, two time differences trace two hyperbolas, their intersection gives the position.

Approach

A lightning strike radiates a VLF pulse propagating at ~c; three synchronised receivers see it arrive at slightly different times. For a source at p and a station at ri:

t_i = || p − r_i || / c  +  n_i

The solver works on time differences relative to a reference station, eliminating the absolute origin. Two solvers are implemented behind the same API:

  • A non-linear least-squares minimizer (SciPy, production path, extensible to N stations)
  • A closed intersection of the two hyperbolas (reference and control)

Key design point: solver.py does not import simulator.py. The solver consumes a simple dict[station_id, t_arrival]. Plugging in real receivers later = writing a new producer, without touching the solver.

Results

  • Three stations on a 50 km equilateral baseline, 100 ns noise: median error ~52 m inside the triangle, < 65 m up to the circumscribed circle.
  • Log-log slope essentially 1 across four decades: the expected linear scaling at fixed geometry.
  • Optimal network size: side ≈ 5× the radius of the area to cover — stations must be far apart, not clustered.
  • The two solvers agree to within 5%; NLLS is retained as it generalises to N stations.

Demo & code

The web demo is a static site (HTML/CSS/JS + Pyodide): the Python library is loaded as-is in the browser, without any JavaScript port. Move the three stations, trigger storms, and watch the solver work.
