Applied Fox

The R&D assistant that never leaves your machine — and never decides in your place. A multi-agent technology-watch system, 100% local via Ollama.

Context

AI tools for engineers suffer from two flaws that can make them harmful to a project: they send your data to servers you don't control, and they tend to take the project over in your place.

Applied Fox is built against those two flaws. The goal: structured, local, human-controlled technology watch, for long projects where knowledge of the context is the main investment.

Approach

You describe your project once in a structured .md file (components, constraints, objectives, next deliverable). Applied Fox runs a chain of 4 local agents that collect, filter, evaluate and synthesise the information relevant to that project, then you validate each suggestion.

Scout        →  Reddit + RSS + GitHub  (deterministic 5-step filtering)
Integrator   →  feasibility assessment
Judge        →  ranking + ETA  (deterministic filters v1.5)
Reporter     →  HTML report + 3-8 prioritised suggestions
                    ↓
              human validation: accept / reject / defer

Each agent has a strict Pydantic contract: if one fails, we know exactly which one and why. The Judge never sees the findings rejected by the Integrator. Three layers of deterministic filters short-circuit ~70% of LLM calls before even querying the model.

Non-negotiable constraints: local by default (no silent network calls, no telemetry), hot-swappable LLM per role, adaptable to the hardware, and the human remains the final arbiter.

Result

  • MVP delivered: interview module (4 modes), 4-agent pipeline, 3 active sources, validation loop, multi-project menu.
  • Full run: ~4-6 min cold, ~1-2 min with a warm LLM cache (RTX 3070 8 GB).
  • The Judge runs in ~10 s on ~20 findings, thanks to the deterministic filters (−70% LLM calls).
  • Zero data sent to a cloud, zero subscription.
